# AWS Full-Stack Todo Application

A production-grade full-stack todo application built with modern technologies and deployed on AWS infrastructure.

## 🚀 Project Overview

This project demonstrates cloud-native architecture, containerization, and DevOps best practices by building a scalable todo application with user management.

## 🛠️ Tech Stack

### Frontend
- React 18 with TypeScript
- Redux Toolkit for state management
- Tailwind CSS for styling
- Vite for build tooling

### Backend
- Node.js with Express
- TypeScript
- TypeORM
- MySQL

### AWS Infrastructure
- API Gateway
- AWS Cognito (Authentication)
- ECS/Fargate (Container orchestration)
- Application Load Balancer
- RDS MySQL (Multi-AZ)
- VPC with public/private subnets
- CloudWatch & X-Ray

### DevOps & Monitoring
- Docker & Docker Compose
- Prometheus & Grafana
- GitHub Actions (CI/CD)
- Infrastructure as Code (Terraform/CDK)

## 📁 Project Structure
```
.
├── frontend/           # React application
├── backend/            # Express API
├── infrastructure/     # Terraform/CDK files
├── docs/              # Documentation
└── docker-compose.yml # Local development
```
